## What it is

**Kadans** (Haitian Creole for *rhythm, cadence*) turns a short JSON description of a video — scenes, texts, voice
lines, brand colors, logo, your own clips and photos — into a self-contained HTML composition, then into an MP4.

**Français.** Kadans transforme une courte description JSON (scènes, textes, voix, couleurs, logo, vos clips)
en une vidéo MP4, avec voix, sous-titres et synchronisation au mot, en **8 langues** — dont le **créole
haïtien** — 100 % en local, sans clé API.

**Kreyòl.** Kadans pran yon ti deskripsyon JSON (sèn, tèks, vwa, koulè, logo, klip ou) epi li fè yon videyo
MP4, ak vwa, sou-tit ak senkronizasyon ak mo yo, an **8 lang** — **kreyòl ayisyen** ladan l — 100 % lokal,
san kle API. Premye motè videyo ki pale kreyòl.

> **Not just an alternative, a complete superset.** Kadans combines the full creative code freedom of HTML/GSAP/Three.js
> with the only thing missing from code-based video engines: it *speaks* — multilingual voices (ElevenLabs or any engine you plug in),
> word-by-word synced captions, Whisper audio QC, generated music and hardware-accelerated rendering in under 2 minutes.

- **8 languages, natural voice.** One spec renders with narration and Studio UI in **FR · EN · HT (Kreyòl) · ES · PT · DE · IT · RU** —
  female and male — from the voice engine the host app plugs in (WASDEV: ElevenLabs, with OpenVoice cloning), cleaned
  in-engine (EQ, de-ess, compressor).
- **Pluggable voice, MIT-safe.** The engine itself is **MIT** and imports no TTS. A voice engine (ElevenLabs,
  OpenVoice cloning, any local text-to-speech command, a future Creole engine…) is passed in and run as a callable or a
  **separate program** (sub-process), so the engine stays MIT even next to GPL tools. **No voice model is ever
  bundled here.** Kadans works with any
  `tts(text, lang, gender, out_wav)` — no specific engine required.
- **HTML & JavaScript creative freedom (GSAP, Three.js, Canvas).** Every scene (the ready-made JSON scene types *and* raw `html` scenes) compiles
  to **one** HTML page rendered **once** — fast. Bring any animation: **GSAP (3.12.5), three.js (0.160.0), anime.js (3.2.1), Lottie (5.12.2),
  Chart.js (4.4.1), motion** are vendored locally (all offline, no CDN needed). Drop any existing **HyperFrames** code right in.
- **HyperFrames Importer.** Convert any HyperFrames project directly with `kadans import-hf <project-folder>` or
  via Python / MCP `was_video_import_hyperframes`. Your GSAP animations, timelines and Three.js canvases run
  as-is while gaining multilingual narration, auto subtitles and sound ducking.
- **Ultra-fast GPU rendering (< 2 minutes vs 19 min).** Automatically detects and activates **NVIDIA NVENC** (`h264_nvenc`),
  **AMD Radeon AMF** (`h264_amf`), **Intel QuickSync** (`h264_qsv`), or **Windows Media Foundation** (`h264_mf`).
  Coupled with parallel multi-workers (default 4+ Chromium instances) and **Frame Deduplication** (resting/static frames
  bypass CDP screen captures and repeat directly into the FFmpeg pipe), render times drop drastically.
- **Cloud & Container Ready.** Zero-dependency HTTP server with `kadans server` and production `Dockerfile` / `docker-compose.yml`
  ready for deployment on AWS Lambda, Google Cloud Run, Modal, or local Docker.
- **AI-native.** An AI writes the spec, Kadans validates it and returns every problem as a precise `path: message`
  list the AI can fix by itself. One prompt → one video.
- **Deterministic.** The page draws any instant with `window.__seek(t)`. Nothing depends on the real clock while
  rendering, so frame 812 is identical on every machine.
- **Preview = render.** Open the composition in a browser: it plays itself with a time bar, using exactly the same
  drawing code the renderer captures.
- **Your media.** Mix animated scenes with your own videos (trimmed, cropped, captioned, with their own sound level)
  and photos (slow push-in).
- **Every format from one spec.** 16:9 · 9:16 · 1:1 · 4:5 · 21:9 · 1.91:1 · 4K — layouts adapt automatically.
- **Real sound.** Voice per scene (your text-to-speech, e.g. ElevenLabs in WASDEV), music generated by FFmpeg from a mood
  and a seed (no samples, no rights to clear, a different piece per seed), your clips' own sound, loudness
  normalized to **-14 LUFS**, `.srt` subtitles. **The voice always stays on top:** music, sound effects and clip
  sound are measured against the voice (EBU R128), kept 4 LU under it, peak-limited and ducked while it speaks
  (`mix: {bed_ceiling, bed_peak, duck}`).
- **Backgrounds and atmosphere layers.** Any scene (or the whole video) can sit on a photo, a looping video or a
  design asset (`background`: fit, opacity, dim for readable text, slow zoom, brand-colour tint), with up to 8
  `overlays` behind or in front of the content — smoke, light, splash, shapes — blended (`screen`, `multiply`…),
  recoloured to the brand, and animated (drift, pulse, spin, float, reveal, sweep). Host apps can expose their
  asset library with `media.set_root("lib", folder)` → `"src": "lib:SMOKE/…/plume_0001.svg"`.
- **27 layer blend modes.** The 17 a browser knows are drawn natively; the 10 no browser has (dissolve, linear burn,
  darker / lighter colour, vivid / linear / pin light, hard mix, subtract, divide) are composited pixel by pixel by
  the renderer (`pip install "kadans-wasdev[blend]"`), the live preview shows the nearest native mode.
- **Every font of the machine.** `kadans fonts` scans the system, user and project `fonts/` folders (TTF, OTF, TTC
  name tables, cached); `brand.font`, `font_title`, `font_code` can be any of them and are embedded with
  `@font-face`, so the render never falls back to another font. Lint reports a missing font.
- **Everything follows the voice.** Word timing comes from a speech recognizer (e.g. Whisper) or is estimated:
  cards, list items, numbers and chips appear on the word that names them, highlighted words pulse when spoken,
  word-by-word animated captions (karaoke / pop), and sound effects (whoosh, pop, hit — generated, no samples)
  land on the cuts and entrances.
- **Cinematic finish.** Bloom, film grain, vignette and motion blur are applied to real pixels *after* capture —
  never as heavy CSS effects that make browser rendering slow and different between machines.
- **Fast re-renders.** Every scene is a cached chunk: change one sentence and only that scene is captured again.
  A render that stops resumes where it was. Several browsers capture in parallel.
- **Lint before render.** Every scene is measured the way a viewer sees it: text outside the safe area, text too long,
  overlaps, missing images or fonts, voice longer than its scene — a JSON report an AI fixes by itself.
- **No license traps, nothing to install.** Pure Python standard library; rendering uses the Edge / Chrome already on
  the machine (headless, private profile, network blocked) — or the Chromium of PySide6 — plus FFmpeg. No Node.js.

## Install

```bash
pip install kadans-wasdev
```

Then let Kadans get what it needs and check everything:

```bash
kadans setup     # FFmpeg (LGPL) + a pinned Chromium, in Kadans' own folder (nothing system-wide)
kadans doctor    # what works, what is missing, and the exact fix (also an MCP tool: kadans_doctor)
```

You can also skip it: the first render downloads, once, whatever is missing (FFmpeg, or Chromium when the computer
has no Edge / Chrome) — set `KADANS_NO_AUTO_SETUP=1` to turn that off. Without `kadans setup` Kadans uses the FFmpeg
on your `PATH` (or `KADANS_FFMPEG`) and the Edge / Chrome already installed. With it, every computer renders with the **same** Chromium version (identical frames).
Your own browser is never changed: rendering runs in an invisible, private, temporary profile.

## Quick start

```json
{
  "kadans": 1,
  "title": "WASDEV launch",
  "lang": "fr",
  "ratio": "9:16",
  "brand": { "name": "WAS*DEV*", "logo": "logo.svg" },
  "scenes": [
    { "type": "hook", "title": "Et si *un seul logiciel* faisait tout ?",
      "voice": "Et si un seul logiciel faisait tout le travail ?" },
    { "type": "video", "src": "clips/demo.mp4", "in": 3, "out": 8,
      "title": "Votre *vidéo*, vos règles", "audio": 0.3 },
    { "type": "features", "title": "Tout pour *créer*", "items": [
        { "icon": "🎨", "title": "Design 2D + 3D" },
        { "icon": "📄", "title": "Documents" },
        { "icon": "🎬", "title": "Vidéos pub" } ] },
    { "type": "cta", "title": "Essayez-le dès aujourd'hui", "subtitle": "wasdev.ai" }
  ]
}
```

```bash
kadans validate spec.json            # ok: 4 scenes, ~14.4 s, 1080x1920 @ 30 fps
kadans html spec.json                # spec.html = live preview with a time bar (open it in a browser)
kadans lint spec.json                # JSON report: layout / timing problems (exit code 2 if any)
kadans frame spec.json --t 6.5       # one PNG, for an AI (or you) to look at
kadans render spec.json -o pub.mp4   # MP4 (GPU-accelerated H.264 + AAC, BT.709) + pub.srt
kadans import-hf ./my-hf-project     # import HyperFrames HTML/GSAP/Canvas into a Kadans spec
kadans server --port 8080            # run HTTP cloud render microservice (Docker / Lambda)
kadans fonts mono                    # fonts installed on this PC (filter by a word)
kadans schema                        # JSON Schema for AI tool definitions
```

Extra spec options: `music {mood: upbeat|calm|epic|tech, seed, volume, file?}`, `look {grain, bloom, vignette}`
(0-1, on by default, `false` = off), `motion_blur: 0|2|4|6`, `progress_bar`, `voice {gender, sample}`,
`captions {style: karaoke|pop, position}`, `sfx {volume}` (on by default, `false` = off), `on` on an item
(the spoken word that makes it appear; by default its own title is looked for in the voice line), and
`background` / `overlays` on the spec or on any scene:

```json
"background": {"src": "clips/city.mp4", "dim": 0.55, "tint": "primary"},
"overlays": [{"src": "lib:SMOKE/01 Rising plumes/plume_0001.svg", "color": "accent", "anim": "drift",
              "x": 0.75, "y": 0.6, "w": 0.7, "opacity": 0.55, "blend": "screen", "layer": "back"}]
```

`*word*` highlights a word with the brand gradient. Durations are optional: a scene lasts as long as its voice line
(or its clip), and never less than its animations need.

## Use it from any AI (MCP)

Kadans ships an **MCP server** (Model Context Protocol, the open standard AI apps use for tools). One server, the
same tools for every AI: Claude (Desktop, Code), ChatGPT / Codex, Gemini CLI, Cursor, VS Code, Windsurf, Cline,
Continue, Zed, LM Studio… It runs on your computer: nothing is uploaded.

```bash
kadans mcp --install claude-desktop     # or: claude-code, codex, gemini, cursor, vscode, windsurf
kadans mcp --print                      # the JSON block to paste into any other MCP client
```

Tools: `kadans_schema` (start here: format + guide), `kadans_validate`, `kadans_lint`, `kadans_frame` (returns an
image: the AI sees the frame), `kadans_preview`, `kadans_render` (background job) + `kadans_status`, `kadans_fonts`,
`kadans_media`.

Voice in the standalone server: set `KADANS_TTS_CMD` to any local text-to-speech command, e.g.
`my-tts --text-file {text} --out {out} --lang {lang}` style tools (placeholders: `{text}` UTF-8 text file, `{out}`
WAV, `{lang}`, `{gender}`). Word timing uses faster-whisper when it is installed, otherwise it is estimated.

## HyperFrames Integration & GSAP Code Freedom

Kadans gives you **100% of HyperFrames's creative coding power** without sacrificing Kadans's voice synthesis, Whisper audio QC, and subtitle engine.

### 1. Import any HyperFrames project directly
```bash
kadans import-hf ./path/to/hyperframes-project -o spec.json
```
This automatically inspects the HTML/JS/CSS, packages dependencies, registers required libraries (`gsap`, `three`, etc.), and produces a ready-to-render Kadans spec.

### 2. Native Vendored Libraries (100% Offline)
Kadans bundles production builds of top animation libraries locally:
- **GSAP 3.12.5**: Full timeline control with `window.tl = gsap.timeline({ paused: true })`
- **Three.js 0.160.0**: 3D WebGL scenes, cameras, meshes, and canvas rendering
- **anime.js 3.2.1**: Fast SVG morphing and micro-animations
- **Lottie 5.12.2**: Vector JSON animations
- **Chart.js 4.4.1**: Dynamic data charts and animated graphs
- **Motion 10.16.4**: Modern physics spring animations

### 3. HyperFrames Timeline Bridge
In any `html` scene, Kadans binds to the standard HyperFrames timeline interface:
```javascript
// GSAP timeline automatically synced:
const tl = gsap.timeline({ paused: true });
tl.to(".box", { x: 200, duration: 2 });
window.tl = tl;

// Or custom timeline hook:
window.onSeek = function(t, sceneT) {
  // t is total video time in seconds, sceneT is time within this scene
};
```

## Hardware-Accelerated GPU Rendering & Deduplication

Kadans renders videos in **under 2 minutes** (down from 19+ minutes on pure CPU):

1. **Automatic GPU Hardware Acceleration**:
   - **NVIDIA**: `h264_nvenc` with NVENC hardware encoding
   - **AMD Radeon**: `h264_amf` with AMF speed profile
   - **Intel**: `h264_qsv` with QuickSync Video
   - **Windows**: `h264_mf` (Media Foundation)
   - Fallback: `libopenh264` (BSD-2-Clause) / `mpeg4` (LGPL) — strictly no GPL encoders (`libx264`/`libx265` are forbidden)
2. **Parallel Multi-Workers**:
   - Renders 4+ Chromium instances concurrently across sliced video chunks.
   - Configure with environment variable `KADANS_WORKERS=4` or API `workers=4`.
3. **Frame Deduplication**:
   - When titles, text slides, or HTML scenes are static (`window.__busy(t) == false`), Kadans skips slow CDP screen capture and repeats the last decoded frame directly into FFmpeg's pipe. This cuts capture overhead by 60%–80%.

## Cloud & Docker Rendering (HTTP API)

Kadans is ready to deploy on **AWS Lambda**, **Google Cloud Run**, **Modal**, **RunPod**, or any Docker host.

### 1. Run local HTTP server
```bash
kadans server --host 0.0.0.0 --port 8080
```
Endpoints:
- `GET /health` — Check server status, FFmpeg availability, and hardware encoder
- `POST /validate` — Validate a JSON spec
- `POST /import-hf` — Convert HTML/GSAP code into a Kadans spec
- `POST /render` — Render a spec and stream the MP4 back directly

### 2. Docker & Docker Compose
```bash
docker compose up -d
curl -X POST http://localhost:8080/render -H "Content-Type: application/json" -d @spec.json --output video.mp4
```

## Python API

```python
import kadans
from kadans import media

spec = kadans.validate(raw_spec)                    # raises kadans.SpecError(.errors = [...])
media_s, clips = media.prepare(spec, base, cache)   # your videos -> frame-exact image sequences (cached)
tl = kadans.timeline(spec, voice_s, media_s)        # real voice / clip lengths -> scene timing
page = kadans.build_html(spec, tl, base, clips, out_dir)

def tts(text, lang, gender, sample, out_wav): ...   # plug any local voice engine
def align(wav, text, lang): ...                     # optional: [[word, start, end], ...] from a speech recognizer
result = kadans.render(spec, "pub.mp4", base, tts=tts, align=align, workers=4,
                       progress=lambda stage, done, total, info: print(stage, done, total, info))
```
