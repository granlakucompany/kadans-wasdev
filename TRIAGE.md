# Issue triage

Labels: `bug` · `enhancement` · `scene-type` · `voice` · `render` · `docs` · `good-first-issue` · `needs-repro`.

## Flow
1. **Needs repro** — ask for the spec + `kadans validate` output + OS/FFmpeg/browser versions.
2. **Confirm** — reproduce locally. Attach the minimal failing spec.
3. **Classify** — bug vs. enhancement; set the area label.
4. **Priority** — P0 (render broken) · P1 (wrong output) · P2 (polish).

A good bug report includes the **spec**, the **command**, and what you expected vs. got.
